# Handoff v19 — 從 10-13 調查借三件：字母先驗除法 + 旋轉平均、數字編號讀出、機率連貫性（2026-10-13，跑前寫死）

來源：`results/10-landscape.md` §11。三件都不訓練、不改 `decide/prompt.py` 的模板本體（E2 只換選項標籤與答案句，走 `render_messages`）。

- **E1 L0**（AnyJev，arXiv 2610.00831）：對選項做 K 次循環旋轉，各讀一次；用無標註資料估「每個位置／字母的先驗」再除掉；取對數平均。他們在 Qwen3-8B 20 類題上：翻轉率 0.23 → 0.07、準確率 +5.6 點、5% 錯誤預算下可自動處理 7.7% → 46.3%。
  我們 v5 T2 試過「順序置換平均」：弱題 −1.3 點，沒過。沒試過的是**除先驗**，以及「旋轉」而非隨機置換。
- **E2 數字編號**（LLM-as-Jev，arXiv 2610.02076）：讀帶括號的數字編號，聲稱零訓練勝過字母讀出。我們一直用 A–J。
- **E3 連貫性**（Beyond Calibration，arXiv 2609.33209）：「是 X」與「不是 X」的機率加起來該是 1。Jev 平均差 0.064、Qwen3.8-27B 第一 token 讀出差 0.293、Jev 三個單標籤機率和 1.14。我們從沒量過。

## 0. 規則

同前：合成資料 D0、依 `pair_id` 分組切分 seed 0（每類 cal 100 / test 100）、26B UD-Q4_K_M、llama.cpp b11371、L4、`--swa-full`、判斷 server 不開 MTP（v18）。
cal 只用來估先驗、擬溫度、定門檻；所有判定在 test。弱題 = 急迫度、SPC、UPH；強題 = 其餘七類。

## 1. 臂與讀法

### E1 L0（十類，全部 200 題，每題 K 次讀取，共約 8,200 次）

旋轉 r 把原選項 j 放到位置 (j + r) mod K，字母照位置排。每次讀取記「位置字母的機率」與「對回原選項的機率」。

| 讀法 | 怎麼算 | 每題讀取 |
|---|---|---|
| **raw** | 旋轉 0（原順序）直接讀 | 1 |
| **rot** | K 個旋轉對回原選項後取**對數平均**（另記 v5 的機率平均） | K |
| **prior** | 旋轉 0，每個字母的機率除以該字母的先驗，再正規化 | 1 |
| **L0** | 每個旋轉先除先驗，再對回原選項取對數平均 | K |

先驗：每類一組，= cal 100 題 × K 個旋轉裡「位置字母機率」的平均。完整旋轉下每個選項在每個位置各出現一次，所以這個平均只剩位置偏好，不含內容。

### E2 數字編號（九類，排除 10 選項的意圖題，test 100 題，約 1,800 次 × 2）

| 臂 | 選項標籤 | 系統句／答案句 | 讀什麼 |
|---|---|---|---|
| letters | A–F（= E1 的 raw，同容器同日） | 現行 | 字母 |
| **N1** | 1–6 | 「只回答一個數字。」／「只回答代表正確選項的數字。」 | 數字 token |
| **N2** | [1]–[6] | 「以 [數字] 回答。」，prefill `[` | `[` 之後的數字 token |

跑前用 `labels.check_labels_llama` 確認 1–9 都是單一 token。
排除十類意圖題的原因：「10」在分詞上不是單一 token，不能跟「1」分開讀。

### E3 連貫性（五個多類題：急迫度、警報分類、SPC、不良根因、工單派送；test 100 題，約 3,000 次）

每題取兩個標籤：X = raw 讀出的 argmax、Y = 正解（X 就是正解時取第二高）。對 X 與 Y 各問：

- (a) 「這個狀況屬於『{label}（{criteria}）』嗎？」 A 是 / B 否 → P(是 X)
- (a′) 同 (a) 但 A 否 / B 是 → 把順序效應分開
- (b) 「這個狀況屬於『{label}』**以外**的類別嗎？」 A 是 / B 否 → P(非 X)

另外急迫度（K=3）每題把三個標籤的 (a) 都問，算單標籤機率和。

指標（全部 raw 機率，另附套用各類溫度後的版本當探索）：
- 否定差 g = |P(是 X) + P(非 X) − 1| 的平均與 95% CI；對照 Jev 0.064、Qwen 0.293。
- 單標籤和 Σ P(是 label)（急迫度）；對照 Jev 1.14。
- 一致性 |P(是 X) − P_K(X)|：yes/no 問法與 K 選 1 問法給同一個標籤的機率差多少。
- 順序效應 |P(是 X)(a) − P(是 X)(a′)|。

## 2. 預測

- E1：rot 弱題 −1 到 0 點（同 v5）；prior 弱題 0 到 +1；L0 弱題 +1 左右，強題不變；raw 的旋轉翻轉率弱題約 20%（v5 量到 21%／19%），prior 降到 15% 以下；5% 預算 coverage 弱題 +0 到 +3 點。**G1 不過。**
- E2：N1 與 letters 差在 ±0.5 點；N2 的 option mass 比 N1 低。**G2 不過。**
- E3：raw 否定差 0.10–0.25，比 Jev 差、比 Qwen 第一 token 好；單標籤和 1.2–1.5；順序效應 0.05–0.15。

## 3. 判定門檻

- **G1 L0 值得當預設**：弱題三類 test 平均 L0 ≥ raw + 0.02，**且** 5% 預算下 coverage L0 ≥ raw + 0.05，**且** 強題七類平均 ≥ raw − 0.005。
  - 副門檻 **G1b 先驗除法免費**：prior（1 次讀取）弱題 ≥ raw + 0.01 且強題不掉 → 採用 prior、不採用旋轉。
- **G2 數字編號**：九類 test 平均 N1 或 N2 ≥ letters + 0.01，**且** 弱題 ≥ +0.02，**且** option mass 中位數 ≥ 0.9。
- **G3 機率可當機率用**：否定差平均 ≤ 0.10。0.10–0.30 → 只能當排序用，門檻照錯誤預算定（現行做法）；≥ 0.30 → 寫進限制，並把連貫性檢查加進 `verify.py`。
- 預測錯了照實寫。McNemar（精確二項）附在每個差上；弱題 300 則的解析度約 ±1 點。

## 4. 結論（2026-10-13，照 §3 填；`results/23-l0-numeric-coherence.md`、`v19.json`）

| 門檻 | 結果 | 判定 |
|---|---|---|
| G1 L0 當預設（弱題 ≥ +0.02、coverage ≥ +0.05、強題不掉） | 弱題 0.867 → 0.867、5% 預算 coverage 0.503 → 0.503、強題 0.994 → 0.996 | **✗** |
| G1b 先驗除法免費（prior 一次讀取） | 弱題 0.867 → 0.867、強題不變。位置先驗量出來幾乎是均勻的（急迫度 0.37／0.34／0.29，其餘差不到 0.03），除掉等於沒除 | **✗** |
| G2 數字編號 N1 ／ N2 | 九類 0.951 → 0.951 ／ 0.952；弱題 0.867 → 0.873 ／ 0.877；mass 1.000。急迫度 −5（p 0.06）、UPH +4（p 0.22），互相抵銷 | **✗** |
| G3 機率連貫性（否定差 ≤ 0.10） | **0.610 ± 0.029**（1,000 對），比 Qwen3.8-27B 第一 token 的 0.293 還差一倍；急迫度單標籤和 1.68（Jev 1.14）；順序效應 0.051 | **≥ 0.30 → 寫進限制** |

三件都沒過，三件的結論都跟預測方向一致，只有數字偏差：
- E1：rot 弱題 0 點（預測 −1 到 0 ✓）、prior 0 點（✓）、L0 0 點（預測約 +1，在容許內 ✓）；raw 旋轉翻轉率弱題 0.110（預測約 20% ✗——v5 的 21%／19% 是 8 種隨機置換，K 次循環旋轉只有 2 到 4 種，翻得少）。
  旋轉平均對 SPC +4、對急迫度 −6（p 0.03），跟 v5 T2 一模一樣的樣子；**AnyJev 的增益來自 20 類題的位置偏差，我們的題 K ≤ 10、位置先驗均勻，沒有東西可以除。**
- E2：N1 與 letters 差 0.000（預測 ±0.5 點 ✓）；N2 mass 沒比 N1 低（兩者都 1.000 ✗）。數字或括號都不改變答案。
- E3：否定差 0.61（預測 0.10–0.25 ✗，差很遠）；單標籤和 1.68（預測 1.2–1.5 ✗）；順序效應 0.051（✓）。

**E3 的跑後診斷（不是門檻）**：對 X（K 選 1 的 argmax，其中 484／505 題 K 選 1 機率 ≥ 0.99）：P(是 X) 平均 0.988，跟 K 選 1 一致；但 P(屬於 X 以外的類別) 平均 **0.768**，70.5% 的題兩個都 ≥ 0.9。
也就是模型對「屬於 X 以外的其他類別嗎」幾乎一律答「是」，連它自己 99% 確定是 X 的題也一樣。對 Y（非 argmax 標籤）P(是 Y) 0.44、P(非 Y) 0.84。
這不是校準問題（兩題各自的 option mass 都 ≈ 1，模板沒壞），是**否定形問法零樣本讀不準**：第一個 token 的機率對「以外」這種措辭沒有做出邏輯上的否定。
Jev 訓練過，否定差 0.064；Qwen 零樣本 0.293；我們 0.61。可能的措辭因素（「以外的其他類別」在中文裡接近雙重否定）沒有另測，列為限制。

**對預設的影響**：三件都不採用，`decide/prompt.py` 與讀法不變。新增兩條規則：
1. **題目不寫否定形**（「是否不需要」「以外」「除了」）；十類現行題目都是肯定形，維持。
2. 第一 token 機率只能當「同一題內選項之間的排序與校準過的信心」用，**不能跨題目做邏輯運算**（P(是 X) + P(非 X) 不等於 1）。寫進 README 的坑與 REPORT §4 限制。
費用：L4 約 0.75 h（smoke + suite），約 $0.6。
